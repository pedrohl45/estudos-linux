## 🖤 O que e esse repositorio?

Esse repo reune tudo que aprendi mexendo com **Shell Script** e **Arch Linux**. Desde scripts simples de manipulacao de arquivos ate a configuracao completa do meu sistema — instalacao, pacotes, personalizacao e tudo mais que fui descobrindo no caminho.

Nao tem segredo: e estudo pratico, erro e acerto, e tudo documentado aqui pra nao esquecer.

---

## 📁 Estrutura

```
📦 shell/
 ┣ 📜 ex01.sh — calculadora com menu (soma, subtracao, mult, divisao)
 ┣ 📜 ex02.sh — remover arquivo
 ┣ 📜 ex03.sh — renomear arquivo
 ┣ 📜 ex04.sh — mover arquivo entre diretorios
 ┣ 📜 ex05.sh — verificar se usuario existe no sistema
 ┣ 📜 ex06.sh — procurar palavra dentro de um arquivo
 ┣ 📜 ex07.sh — buscar arquivos com find, whereis e locate
 ┣ 📜 ex08.sh — concatenar arquivos
 ┣ 📜 ex09.sh — comparar dois arquivos com diff
 ┣ 📜 ex10.sh — informacoes de um usuario do sistema
 ┣ 📜 ex11.sh — listar usuarios conectados
 ┣ 📜 ex12.sh — alterar permissoes de arquivo (chmod)
 ┣ 📜 ex13.sh — listar processos (ps aux)
 ┣ 📜 ex14.sh — procurar processo por nome
 ┣ 📜 ex15.sh — encerrar processo por PID
 ┣ 📜 ex16.sh — informacoes do kernel (uname)
 ┣ 📜 ex17.sh — contar linhas, palavras e caracteres de um arquivo
 ┣ 📜 ex18.sh — painel rapido do sistema (data, kernel, uptime)
 ┣ 📜 ex19.sh — menu interativo de informacoes do sistema
 ┗ 📜 ex20.sh — menu completo de gerenciamento de arquivos
```
